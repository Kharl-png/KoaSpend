# KoaSpend

React + Vite + TypeScript frontend in `app/web`.

Run these commands from the repository root:

```sh
npm install
npm run dev
```

Edit `app/web/src/App.tsx` to change the page. Run `npm run typecheck`
to check types, `npm run lint` to lint, and `npm run build` to check types
and create the production build in `app/web/dist`.
